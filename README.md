# Il genio e i mattoncini

Presentazione 3D riservata · Flazio × Aruba.

Apri `index.html` con Chrome (funziona anche offline: font, immagini e codice sono tutti dentro il file).

## Comandi

- Scroll, frecce ← → o barra spaziatrice: tappa successiva o precedente
- N: note per chi presenta
- I: indice
- F: schermo intero

I numeri di Lovable e le stime sui token sono illustrativi e segnati come tali nelle slide.
